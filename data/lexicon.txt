# psnb-obs 触发词观测清单（lexicon）
#
# 作用：差分挖掘产出的是重叠 n-gram，光靠频率无法区分「真触发词」和「跨界碎片」。
#       这份清单提供先验，让挖掘优先选真实词形（`薅羊毛` 而不是 `薅羊毛脚`）。
#
# 与 wording_map.json 的分工：
#   lexicon  = 观测清单（发现即登记，零风险，只影响挖掘排序）
#   map      = 生效映射（必须经实测验证才能进，因为会改动出站文本）
#
# 格式：一行一个词，# 开头为注释。evolve 消融确认后可自动追加到这里。
